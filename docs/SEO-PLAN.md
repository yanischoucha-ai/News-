# Plan SEO par pilier (clusters)

Principe : un site jeune gagne sur la longue traîne à intention business, pas sur les mots-clés génériques. Volumes non mesurés : difficulté qualitative (F/M/E) à confirmer dans la Search Console après 3 mois. Chaque cluster = 1 page pilier + des articles satellites + 1 outil gratuit. Avant d'écrire, vérifier le top 5 des résultats (format, sous-thèmes, questions « autres questions posées ») et couvrir mieux ou autrement.

Règles d'écriture SEO (s'ajoutent à EDITORIAL.md) : titre ≤ 60 caractères avec le sujet en premier (le détail va dans le sous-titre), description 140–160 caractères avec un bénéfice, réponse directe en 40–60 mots au début de chaque section clé, 3 à 5 liens internes (article, outil, page pilier), mise à jour datée.

## Backlinks (sans achat ni réseau douteux)
Les outils gratuits sont les meilleurs aimants à liens. Actions naturelles : proposer les calculateurs aux sources déjà citées quand ils complètent leur page, publier des données refaisables que d'autres peuvent citer, répondre honnêtement aux questions de communautés (sans spam). Suivi : Search Console > Liens, chaque lundi.

## Revue (3 mois, puis chaque trimestre)
Search Console : impressions, clics, requêtes par pilier. Pilier sans impressions après 3 mois : renforcer avec un outil et 3 articles ciblés, sinon le remplacer. Aucune décision sur des suppositions : seuls les chiffres comptent.
